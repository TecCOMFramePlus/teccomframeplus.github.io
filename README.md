# TecCOMFrame+ website

Static project page for TecCOMFrame+, served via GitHub Pages at <https://teccomframeplus.github.io/>.

Plain HTML and CSS, no build step:

- `index.html` – the page
- `assets/css/style.css` – styles
- `assets/img/` – project logo and the "Co-funded by the European Union" emblem

To preview locally, open `index.html` in a browser. Changes pushed to `main` are published automatically.
